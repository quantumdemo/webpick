Frequently asked questions

About the free tools, their limits and the Chrome extension.

What is Sitepeel?

Sitepeel is a set of free website tools for web developers and designers. Paste a link to clone a site with AI, or get its DESIGN.md, assets, fonts, colors, tech stack, screen sizes or a full-page screenshot. The Sitepeel Chrome extension adds 13 more tools that work on any page you open.

Are the tools free?

Yes. The website tools are free and need no install. Clone prompt, DESIGN.md and the asset extractor ask you to sign in after a few runs; lifetime access makes them unlimited and saves your results.

What is a DESIGN.md file?

A Markdown file that describes a design system: colors, typography, spacing, corners and components. Link it from your AI agent’s instructions (CLAUDE.md, AGENTS.md or Cursor rules) and Claude Code, Cursor or Codex build interfaces that match it.

Does it work on any website?

It works on public pages. Some sites block automated visits, and pages behind a login need the Sitepeel Chrome extension, which works on the page you have open.

Can I reuse what I extract?

Images, fonts, code and copy belong to the site’s owner. Use them as reference, or ask for permission before you reuse them.
